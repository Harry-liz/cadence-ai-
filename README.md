# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/ef50bee1-e5cf-4e15-b2c2-dfbcb2899e27

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
--------暂时性的浏览方式-----------
4. 按住ctrl，再点击terminal里面的网址
5. 进入浏览器之后点击F12打开开发者模式，点击开发者工具的左上角toggle device emulation,
6. 在页面的左上角找到dimentions，选择Iphone 12 Pro，预览体验最好。
7. 可以点击F11，全屏画面，沉浸式体验
